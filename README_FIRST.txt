MARL STOCK EXCHANGE - START HERE
================================
1. Read MARL_Stock_Exchange_Workshop.docx.
2. Run SETUP_ONCE.bat once.
3. Run START_HERE.bat.
4. Work through mini-examples 1-5 before training the starter DQN.
5. Edit only your own model/training work under student_work/ (and your own extra experiment files).
6. Do not change shared/contract.py: it is the common competition interface.
7. Export the final TEAM_XX.zip using START_HERE.bat option 9.
8. Validate the exact ZIP before upload.

The mini-examples are intentionally short. The full task is not simplified: teams are
expected to improve training, reward design, robustness and/or model architecture while
preserving the fixed competition contract.
