WORKSHOP MINI-EXAMPLES
======================
These scripts are deliberately small and runnable. They use the same observation and
action contract as the final model.

Run from the Student_Package root after SETUP_ONCE.bat:

  .venv\Scripts\python.exe -m examples.demo_01_observe_market
  .venv\Scripts\python.exe -m examples.demo_02_rule_based_agent
  .venv\Scripts\python.exe -m examples.demo_03_actions_and_reward
  .venv\Scripts\python.exe -m examples.demo_04_network_forward
  .venv\Scripts\python.exe -m examples.demo_05_one_dqn_update

The examples are learning aids. The assessed model is built in student_work/.
